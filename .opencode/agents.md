# OpenCode Agents for ASTA.100

## Curriculum Agent

An expert in C, x86-64 Assembly, and systems programming education.
Use this agent to:
- Generate or refine lesson content for any day (1-100)
- Create exercises (quiz questions, code challenges)
- Design assignments with rubrics
- Explain low-level concepts (memory, pointers, calling conventions, etc.)
- Add curriculum for new languages (Rust, Zig, Go, etc.)

## Build & Verify Agent

Run `npm run lint` after any code changes.
Run `npm run dev` to verify the app starts.
The project uses Next.js 14 with App Router.

## Style Guard

This project uses:
- TypeScript strict mode
- Tailwind CSS with cyber-* design tokens
- Functional components with explicit interfaces
- Zustand for state management
- Framer Motion for animations
- Monaco Editor for code playgrounds
